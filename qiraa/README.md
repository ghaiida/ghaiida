# سُلَّم القراءة — من الحرف إلى الكلمة

كتاب تعليم القراءة للأطفال (KG3) بطريقة **البناء التراكمي**:
المقطع الأول ← الثاني ← نجمعهما ← الثالث ← الكلمة كاملة (رَ ← سَ ← رَسَ ← مَ ← رَسَمَ).

- `sullam-alqiraa.pdf` — الكتاب جاهز للطباعة (A4، ٩٨ صفحة).
- `../qiraa.html` — نفس الكتاب للعرض في المتصفح (زر «اطبع الكتاب»).

## المحتوى
دليل ولي الأمر + لوحة الرحلة، ثم ٨ مراحل:
١ الحروف مع الفتحة (٢٧ درسًا، صفحتان لكل حرف، و٥ محطات مراجعة) ·
٢ الضمة والكسرة · ٣ التنوين وحرف الياء · ٤ السكون · ٥ المدود ·
٦ الشدة · ٧ ة وال القمرية والشمسية وء وى · ٨ الجمل والقصص،
ثم بطاقات حروف للقص وشهادة «بطل القراءة».

## التعديل وإعادة البناء
المحتوى كله في `content.py` (الكلمات والصور والنصائح)، والتصميم في `style.css`.

```bash
python3 qiraa/build.py   # يولّد qiraa.html
node qiraa/pdf.js        # يولّد PDF ويفحص أن لا صفحة يفيض محتواها
```
